Лабораторная работа №1. Интерфейс работы со структурами данных (мини-СУБД).

Запуск:
./dbms --file file.data --query 'КОМАНДА имя [аргументы]'

Файл: одна строка — одна структура: ТИП имя элемент1 элемент2 ...
ТИП — первая буква команд этой структуры (M, F, L, S, Q, T).
Стек записывается от дна к вершине, очередь — от начала к концу.
Дерево записывается парами "ключ цвет" в прямом обходе (корень, левое, правое),
поэтому при следующем запуске оно восстанавливается точно таким же.

Индексы считаются с 0. Результат команды выводится как "-> значение".

PRINT имя                     вывести любую структуру (массив, списки, стек, очередь, дерево)

Массив (M)
MCREATE имя                   создать пустой массив
MPUSH имя значение            добавить в конец
MINSERT имя индекс значение   добавить по индексу
MGET имя индекс               получить по индексу
MDEL имя индекс               удалить по индексу
MSET имя индекс значение      заменить по индексу
MLEN имя                      получить длину массива

Односвязный список (F)
FCREATE имя                   создать пустой список
FPUSH имя значение            добавить в конец
FPUSH имя значение front      добавить в начало
FINSERTAFTER имя цель значение    добавить после элемента
FINSERTBEFORE имя цель значение   добавить перед элементом
FDEL имя значение             удалить по значению
FDELHEAD имя                  удалить первый элемент (голову)
FDELTAIL имя                  удалить последний элемент (хвост)
FDELAFTER имя цель            удалить элемент после указанного
FDELBEFORE имя цель           удалить элемент перед указанным
FGET имя значение             проверить наличие (TRUE/FALSE)
FGETFIRST имя                 прочитать первый элемент
FGETLAST имя                  прочитать последний элемент

Двусвязный список (L)
LCREATE имя                   создать пустой список
LPUSH имя значение            добавить в конец
LPUSH имя значение front      добавить в начало
LINSERTAFTER имя цель значение    добавить после элемента
LINSERTBEFORE имя цель значение   добавить перед элементом
LDEL имя значение             удалить по значению
LDELHEAD имя                  удалить первый элемент (голову)
LDELTAIL имя                  удалить последний элемент (хвост)
LDELAFTER имя цель            удалить элемент после указанного
LDELBEFORE имя цель           удалить элемент перед указанным
LGET имя значение             проверить наличие (TRUE/FALSE)
LGETFIRST имя                 прочитать первый элемент
LGETLAST имя                  прочитать последний элемент

Стек (S)
SCREATE имя                   создать пустой стек
SPUSH имя значение            добавить в конец (на вершину)
SPOP имя                      извлечь из конца (с вершины)
SGET имя                      прочитать верхний элемент (без удаления)

Очередь (Q)
QCREATE имя                   создать пустую очередь
QPUSH имя значение            добавить в конец
QPOP имя                      извлечь из начала
QGET имя                      прочитать первый элемент (без удаления)

Дерево (T) - Красно-черное
TCREATE имя                   создать пустое дерево
TINSERT имя значение          добавить элемент
TGET имя значение             проверить наличие (TRUE/FALSE)
TDEL имя значение             удалить элемент
